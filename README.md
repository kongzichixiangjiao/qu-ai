# qu-ai · 超能去AI

> 不是换词，是换魂。让AI写的字，读起来像人写的。

---

## 为什么你需要它？

你肯定见过这种文字——

读起来很顺，顺到发腻。每句话长度差不多，每个段落格式一样，用词准确但毫无性格。你看完了，但一个字也没记住。

这就是 **AI 味儿**。你的读者、老板、客户，都能闻出来。

`qu-ai` 是来解决这个问题的。它不止换词换句式，而是从 **语言、叙事、细节、设定** 四个维度，系统性把 AI 的文字改成真人写的——有瑕疵、有温度、有私人记忆、有不讲道理的联想。

## 效果对比

### 场景一：自媒体观点文

**改前（AI味）** ：
> 在当今快节奏的职场环境中，高效沟通已成为个人竞争力的核心要素。然而，许多职场人士往往忽视了沟通的本质——不是表达自己，而是理解他人。这种现象值得我们深入反思。

**改后（qu-ai）** ：
> 说个事儿。
> 上周开会，一个同事讲了四十分钟，PPT翻了几十页。散会后我问旁边的人：他到底想说什么？对方摇了摇头。
> 你看，职场上绝大多数人不是在沟通，是在输出。这两件事差远了。

### 场景二：生活随笔

**改前（AI味）** ：
> 周末的午后，阳光透过窗帘洒在地板上，我泡了一杯茶，翻开一本买了很久却没时间读的书。这样的慢时光让人感到无比惬意，也让我重新思考生活的意义。

**改后（qu-ai）** ：
> 周六。本来计划好要干三件事：修水龙头、去银行、整理衣柜。结果泡了杯茶，往沙发上一坐，三点了。书倒是翻了二十页——还是那本年初买的，到现在没看完第一章。
> 算了，水龙头还能再用一周。

### 场景三：职场周报（保留数据，去掉AI腔）

**改前（AI味）** ：
> 本周Q3项目按计划稳步推进，各模块完成度符合预期。通过跨部门协同，我们有效解决了资源瓶颈问题，为下一阶段工作奠定了坚实基础。

**改后（qu-ai）** ：
> Q3项目本周进度：三条线里两条正常，一条比计划晚了三天。原因是设计那边人手不够，周二拉上产品老大一起开了个短会，临时调了两个人过来。下周继续追进度，目标不变。

## 跟「换个说法」有什么不一样？

市面上大多数去 AI 工具只做一件事：**换词**。把「此外」换成「另外」，把「总而言之」换成「总的来说」。

`qu-ai` 的改写是**四维穿透**的：

| 维度 | 它在干嘛 | AI 的死穴 |
|:-----|:--------|:----------|
| **语言层** | 打散句式、清洗模板词、让句子有呼吸感 | AI 的句子太工整、太「对」、读完全忘 |
| **叙事层** | 打破模板结构、加入干扰项、让主角犯错 | AI 笔下人物全员通透、伏笔零浪费、推理不犯错 |
| **细节层** | 通用细节 → 私人记忆、功能道具 → 无用闲笔 | AI 的细节从网上抓的，没有体温 |
| **设定层** | 多角色文风差异化、打破模板人设 | AI 标榜「多位作者」但文风完全一样 |

简单说：别的工具是给文字**换衣服**，`qu-ai` 是给文字**换骨血**。

## 怎么用？

### 1. 安装

把 `qu-ai` 放到你的 Claude Code skills 目录下：

```bash
# 在你的项目 .claude/skills/ 下
git clone git@github.com:kongzichixiangjiao/qu-ai.git
```

### 2. 触发

把 AI 写的文字贴出来，说任意一句即可自动触发：

> 「去AI痕迹」
> 「太像AI写的了，帮我改改」
> 「去机器味儿」
> 「这看着太AI了」

### 3. 自动匹配角色

`qu-ai` 会分析你的文字内容，自动匹配 **13 个专业编辑角色**中最合适的一个来改写——

| 角色 | 你的文字里出现这些词 |
|:-----|:---------------------|
| 🏢 商业分析师 | 市场、行业、ROI、GMV、财报… |
| 🎮 产品测评人 | 上手、手感、开箱、性价比… |
| 💻 技术写手 | 代码、API、部署、Bug… |
| ✍️ 自媒体观点文 | 你应该、别再、说真的… |
| 📊 职场汇报人 | 周报、OKR、KPI、复盘… |
| 🎯 品牌文案 | 品牌、调性、slogan… |
| 📖 小说作者 | 叙事、对话、场景描写… |
| 🍵 生活随笔 | 周末、孩子、做饭、想起以前… |
| 📱 社交媒体小编 | emoji、姐妹们、安利、避雷… |
| 🔬 知识科普作者 | 为什么、原理、打个比方… |
| 🎬 视频脚本 | 各位、今天聊、记得点赞… |
| 🎤 演讲稿/致辞 | 尊敬的、很荣幸、展望… |
| 🧰 通用编辑 | 以上都不匹配时兜底 |

## ⚠️ 注意：不是所有文字都需要去 AI

✅ **适用**：创意写作、自媒体、小说、随笔、社交媒体、演讲稿、视频脚本

❌ **不适用**：学术论文、法律文书、新闻报道、技术文档

原因很简单：`qu-ai` 会**主动加入原文没有的内容**——私人记忆、闲笔、感官联想——这对小说是「注入人味儿」，对论文是「编造数据」。请根据场景自行判断。
