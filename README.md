# ultra-remove-ai — 去AI痕迹

> 不是简单的"去AI痕迹"，而是真正注入人味儿——有性格、有情绪、有瑕疵、有温度。

## 是什么

一个 Claude Code Skill，内置 **13个专业编辑角色**，自动匹配文字类型，用最合适的口吻把AI生成的文字改成真人写的。

## 触发词

去AI痕迹 · 去AI味 · 这看着太AI了 · 帮我润色成人写的 · 太像AI了帮我改改 · 去机器味儿

## 角色列表

| # | 角色 | 匹配信号 |
|---|------|---------|
| 00 | 通用编辑 | 兜底角色 |
| 01 | 商业分析师 | 市场、行业、赛道、ROI、GMV、财报… |
| 02 | 产品测评人 | 上手、手感、体验、开箱、性价比… |
| 03 | 技术写手 | 代码、部署、API、Bug、架构… |
| 04 | 自媒体观点文 | 你应该、别再、说真的、终于知道… |
| 05 | 职场汇报人 | 周报、OKR、KPI、复盘、述职… |
| 06 | 品牌文案 | 品牌、调性、slogan、campaign… |
| 07 | 小说作者 | 叙事文、人物对话、场景描写… |
| 08 | 生活随笔 | 生活、周末、孩子、做饭、想起以前… |
| 09 | 社交媒体小编 | emoji、姐妹们、安利、避雷… |
| 10 | 知识科普作者 | 为什么、原理、打个比方、冷知识… |
| 11 | 视频脚本 | 各位、今天聊、记得点赞、评论区… |
| 12 | 演讲稿/致辞 | 尊敬的、各位、很荣幸、展望… |

## 工作流程

```
分析原文 → 分类匹配角色 → 加载角色指令 → 运用共享技法重写 → 质量自检
```
