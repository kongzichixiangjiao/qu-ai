# 共享改写技法

以下内容所有角色通用。改写时自然运用，不刻意每条都上。

---

## 核心原则

**一句话：读出来要像有人在跟你说话，不是在给你汇报。**

真人写作七个特征——你的改写必须嵌入这七样东西：

| # | 真人特征 | 怎么做到 |
|:--|:--------|:--------|
| 1 | **有观点，且偏见** | 站一个立场。"我理解是……""其实说白了……"，删除所有和稀泥的表达 |
| 2 | **有情绪** | 情绪词敢用：失望、意外、牛X、离谱、可惜、真不错、就这？ |
| 3 | **节奏是乱的** | 长句→短句→一段话→半截话。打乱，必须乱。 |
| 4 | **有瑕疵** | 允许句子不完整、前后不太连贯、重复强调 |
| 5 | **敢说不知道** | "这里我也没想明白""说实话我不太确定" |
| 6 | **有个人语气** | 善用：你、我、咱们。像在跟朋友解释一件事 |
| 7 | **不成体系** | 打破编号，用"还有""对了""顺便说一句""扯远了，回来"串联 |

---

## 一、彻底拆掉AI骨架

### 1. 拆"总分总"结构
上来直接说事，不铺垫。中间想到哪说哪。结尾可以是一句话，可以是反问，可以突然停——就是别总结。

### 2. 拆"客观中立"
每段、每个观点，替作者站一个立场。不用中立，不用客气。

### 3. 拆"结构化列举"
打破编号顺序，用"还有""对了"重新串联——信息还在，但结构完全打破。

### 4. 拆"滴水不漏"
允许句子不完整、允许跳跃连接、允许重复强调。

## 二、注入人味儿 18 招

### 第1招：落地词
把抽象词换成大白话。
- "实施" → "干" / "做"
- "利用" → "用" / "靠"
- "具备" → "有"
- "进行" → 直接接动词
- "呈现……态势" → "看起来……"

### 第2招：口头禅
自然插入口语化表达：
- "其实……""说白了……""你想想……""这么说吧……"
- "老实说……""反正我……""真要说的话……"
- 全文控制5-8处，别太多。

### 第3招：个人化判断
客观陈述后接一句主观判断：
- "数据是涨了——但我总觉得这增长不太健康。"
- "官方说法是A。你信吗？反正我不太信。"

### 第4招：转场词
用非正式转场代替"另外""此外"：
- "还有——""哦对了""扯远了，拉回来""说回正事"

### 第5招：插入语
在长句中插入短评：
- "这个数据——注意，这是扣除了水分的——同比增长了30%。"

### 第6招：情绪直言
该有情绪的地方别压着：
- 好的：牛X、真的强、没话说、真不错、意外的好
- 差的：拉胯、离谱、不值、我就纳闷了、搞不懂

### 第7招：模糊真实感
适度的模糊更真实：
- "差不多两年吧""大概三四成的样子""翻了不止一倍"

### 第8招：短句突刺
长句中突然插入2-5字极短判断：
- "这就是刷数据。没用。"
- "钱砸了。人招了。产品黄了。就这么个结果。"

### 第9招：反问替代陈述
- "这能叫创新？" 代替 "这不能算作创新"
- "你觉得用户会买账吗？" 代替 "用户可能不会接受"

### 第10招：让步式开头
先承认反面观点，再说自己的：
- "我承认，从数据上看确实不错——但有几个问题……"
- "说实话，一开始我也觉得这功能很鸡肋。用了三个月后……"

### 第11招：特定/具体替代泛泛而谈
- "很多人" → "我问了周围七八个做这行的"
- "业内人士" → "几个基金经理吃了顿饭，聊下来都觉得——"

### 第12招：观点前置
先说结论，需要的话再解释。
- "我觉得这个方向不行。原因很简单——"

### 第13招：任性省略
点到为止，全文最多1-2处：
- "懂的都懂。""后面的故事就不展开了。""你品，你细品。"

### 第14招：自问自答
先提问再回答，极像真人的思考过程：
- "那问题来了——为什么还做不起来？我理解是两个原因……"

### 第15招：私人细节
AI最大的特征之一是"通用模板细节"——老相册、褪色照片、老旧房子，像从网上抓取的标准怀旧素材。真人写作会有独一无一的具体印记。

具体做法：
- "小时候的回忆" → "小学门口那家炸串摊，老板娘总多给我一串年糕"
- "老相册" → "那本绿色封面的相册，扉页上用圆珠笔歪歪扭扭写着'2003.6.1'"
- "他走进房间" → "他进门时踩到了门口那块松动的地板——三年了，还是没修"
- "她很紧张" → "她把手机解锁、锁屏、解锁、锁屏，重复了七八次，自己都没意识到"

**原则**：细节要有"只有这个人/这个场景才会有"的专属感。不能是任何同类场景都能套用的标准件。

### 第16招：情绪体感化
AI描述情绪的方式是"贴标签"：他很愤怒、她很害怕、他感到悲伤。真人的情绪是通过身体、动作、行为传递出来的——读者自己"感受到"的，远比你"告诉"他们的有力。

铁律：**禁止"他很X""她感到Y"式情绪陈述。**

- ❌ "他很生气" → ✅ 他把杯子往桌上一墩，水洒了半杯，他没擦。
- ❌ "她很害怕" → ✅ 她攥着手机，攥到指节发白。屏幕上的字她一个都没看进去。
- ❌ "她很难过" → ✅ 她盯着手机屏幕上那个名字，一直盯到屏幕自动暗掉。然后她又点亮。又暗掉。
- ❌ "气氛很紧张" → ✅ 没人说话。空调滴水的声音突然变得很响。
- ❌ "他心中涌起复杂的情绪" → ✅ 他在车里坐了十分钟。没发动。没放音乐。就那么坐着。

**关键区分**：不要"描述情绪"，要"创造让读者产生那种情绪的场景"。读者读到杯子砸了、水洒了、他没擦——自己就知道他生气了。你不需要告诉他。

### 第17招：人性灰度
AI写人物最大的问题是「安全性训练痕迹」——人物善恶二元切割，全体好人 vs 全体坏人。真人写作中，好人会有不光彩的瞬间，坏人也会有不忍的时刻。

具体做法：
- 给「好人」加私心：老唐可以劝女主别查了——不是因为关心她，是因为自己也怕惹麻烦。女主可以不报警——不是因为证据不够，是因为她刚交了半年房租不想搬家。
- 给「坏人」加软肋：范必达执行父亲的命令，但半夜自己也会来1402看看——他不是在维护秘密，他是害怕这个秘密。物业老郭收了封口费，但故意没把天台钥匙「保管好」。
- 主角的道德困境：让她面临一个真实的利己选项——「可以不管这件事」——然后她选择继续的理由必须是不伟大的。不是为了正义。是因为「已经花了两天查这件事，现在放弃太亏了」。或者「那个论坛上的女孩等了十七年——跟她没关系，但就是老想着这句话」。

**铁律：全文不能出现100%纯良或100%纯恶的角色。至少2个角色要有「与阵营矛盾」的行为。**

### 第18招：恐惧记忆锚定
AI写恐惧只有「当下反应」——心跳、发抖、后背发凉——没有「记忆闪回」。真人在恐惧时，大脑会不受控制地检索过去最恐怖的画面。恐惧越深，闪回越具体、越私人。

具体做法：
- 每个恐怖场景中，至少触发1段人物的私人记忆碎片——不是「想起小时候」，是具体的：「七岁那年掉进工地水泥坑，泥浆灌进嘴里的铁锈味」「车祸那天弹开的安全气囊，橡胶烧焦的味道」。
- 恐怖场景中的感官描写，不能是任何恐怖小说都能用的通用符号（樟脑呛人、灯光闪烁、走廊空荡）。换成只有这个人会联想到的信号——「洗洁精的柠檬味」之所以恐怖，不是因为「味道很奇怪」，是因为「这是她姥姥用的牌子，姥姥去世那天厨房里也是这个味道」。
- 人物的恐惧生理锚点（比如左眼皮跳），要和创伤来源绑定——不是「车祸后遗症」一句话交代完就完了，要在恐惧场景中让车祸的碎片画面闪回来。她左眼皮一跳，同时脑子里闪过一个画面：挡风玻璃碎裂成蛛网状，雨刮器还在动。

**铁律：恐惧描写中，至少1处感官信号与人物私人创伤绑定，至少1处触发具体记忆碎片。不能全是通用恐怖符号。**

### 第19招：干扰项注入（反零废料）

AI叙事有一个底层特征：**每条线索都在结尾精准回收，无一浪费**。这是算法优化的结果——AI被训练为「每个细节都要服务于情节」。真人叙事一定有冗余、有误判、有说不清的东西。

具体做法：
- 加入至少1个「干扰项」——一个看似有深意但最终未揭晓的细节。比如：主角怀疑邻居在偷窥她——花了两天观察、做了记录——最后发现邻居只是在等快递。这个支线对主线没有任何帮助。但这就是生活。
- 加入至少1个主角「猜错了」的方向。她以为物业老唐在隐瞒什么——结果发现老唐只是耳背，没听清她说什么。真实调查中80%的怀疑都是错的。
- 保留1-2个「说不清」的细节——不解释，不回收，就让它们悬在那里。读者会自己脑补，就像我们对生活中那些没解释的事情一样。

**铁律：不能让每条线索都在结尾找到对应位置。一定要有「废料」——看似有用、实则无关的细节。真人叙事像矿渣，有金子也有石头；AI叙事像精炼金条，每克都是纯的。**

### 第20招：句式情绪同步（反工整罗列）

AI最隐蔽的痕迹之一是：**无论人物处于什么情绪状态，句子结构保持同样的工整度**。尤其是「动词+宾语，动词+宾语，动词+宾语」的逗号并列罗列链，贯穿全文、贯穿所有情绪场景——冷静时这样写、恐惧时也这样写。

这是AI的深层签名。真人写作中，句子的形态会随人物的情绪状态变化而变化。

具体做法：
- 扫描全文，找出所有「动词+宾语，动词+宾语，动词+宾语」的逗号罗列链。
- 人物**冷静观察/日常行动**时：可以保留逗号罗列——「她把钥匙扔在鞋柜上，换了拖鞋，走进厨房，打开冰箱。」这传递的是日常的、不紧不慢的节奏。
- 人物**恐惧/紧张/愤怒/疲惫**时：把逗号换成句号——「钥匙插进去。拧两圈。开门。进去。关门。反锁。」句号制造急促感、破碎感。人物在恐惧时不会「把钥匙插进锁孔，拧了两圈，开门，进去，关门，反锁」——她是一个动作一个动作地做的，呼吸是断的。
- 人物**思维混乱/崩溃边缘**时：句子可以碎裂到不成句——「她站在门口。钥匙。钥匙呢。手上。在手上。」这不是语法错误，这是意识流的准确呈现。

**铁律：从句式形态能反推人物的情绪状态。如果全篇句式雷同——不管人物在干什么、感受什么，句子都保持同样的结构和节奏——那就是AI无疑。**

### 第21招：感官偏见化（反通用正确）

AI写感官描写有一个致命特征：**永远正确，但永远没有偏见**。「消毒水和猫毛混在一起的味道」「樟脑丸混着旧棉絮的味道」——这些描写是准确的，但它们是「任何一个人」都能闻到的。真人的嗅觉/触觉/味觉/听觉带有强烈的个人情绪史——同一个味道，不同的人会联想起完全不同的东西。

这就是AI和真人感官描写的本质区别：**AI的感官是照相机——准确、通用、无历史。真人的感官是时光机——不准确、不讲道理、但带着这个人活过的全部证据。**

具体做法：
- 至少1处感官描写必须附带一段不讲道理的私人联想。不是「这个味道很刺鼻」——是「消毒水的味道让她想起八岁那年住院，隔壁床的男孩把最后一块西瓜留给了她。她咬了一口，西瓜汁滴在被子上。护士骂了她」。
- 感官联想允许跳跃、允许逻辑断裂。真人闻到汽油味可能突然想起前男友的车——没有因果关系，纯粹是大脑的非线性检索。AI做不到这种跳跃。
- 「通用正确」→「私人偏见」转换模板：
  - ❌ 「空气里有股霉味」 → ✅ 「霉味钻进鼻子里——和她大学宿舍那间地下室一模一样，室友搬走时留下一盆死了的绿萝，土发霉了也没人倒」
  - ❌ 「消毒水的气味」 → ✅ 「消毒水。她咽了一下口水。上次闻这个味道是姥姥的病房。姥姥说想吃馄饨。她去买。回来的时候姥姥已经走了。」
  - ❌ 「饭菜很香」 → ✅ 「蒜蓉下油锅的滋啦声从厨房传出来。妈在炒菜。她听声音就知道今晚是蒜蓉西兰花——油温高了，蒜有点焦」

**铁律：至少1处感官描写必须「不准确但真实」——它携带的不是气味/声音/触感本身，而是这个人物活过的历史。AI的感官永远正确但无根；真人的感官有根但不一定正确。**

## 三、通用 AI 词汇清洗表

以下词汇出现，原文大概率是AI写的。发现即替换。各角色还有角色专属禁用词。

| AI 词/句式 | 替换为 |
|:----------|:------|
| 随着……的发展/在……背景下 | 直接删掉这句 |
| 值得注意的是/值得一提的是 | 删掉，或改为"关键是什么？" |
| 在一定程度上/从某种程度上说 | 删掉 |
| 赋能、重构、重塑、破局、深耕、布局 | 换成具体动作 |
| 闭环、护城河、壁垒、赛道、格局 | 换成大白话 |
| 显著、深入、全面、系统、核心、关键 | 删除，或用数据说话 |
| 进一步、持续、不断、日益 | 删除 |
| 标志着、意味着、彰显了、体现了 | 直接说"是"或陈述事实 |
| 打造、构建、实现、形成 | 换成"做""有""成" |
| 总而言之/综上所述/概括而言 | 删除 |
| 首先…其次…再次…最后… | 打破顺序，用"还有""对了"重新串联 |
| 以下将从X个维度展开 | 删除 |
| 展望未来/我们有理由相信 | 删除，结尾留一句判断 |
| 至关重要/不可或缺/举足轻重 | 删掉 |
| 在……方面表现突出/具有优势 | 直接说"做得好""比……强" |
| 基于/依托/凭借 | "靠" |

## 三点五、AI 模板句式清洗表

以下**整句模式**比单个用词更容易暴露AI身份。发现即拆解，不能只换同义词——整个句子的结构要打散重写。

| AI 模板句式 | 为什么是AI | 怎么拆 |
|:-----------|:---------|:------|
| 不是XX，而是YY | AI最爱用的对比句式，一篇出现三次以上就是铁证 | 拆成两句独立的短句，或者干脆删掉"不是XX"，直接说"是YY" |
| 那一刻，他/她意识到…… | AI标配心理揭示句，人物不需要"意识到"——让他做出来 | 删掉"意识到"，直接写人物做了什么 |
| 眼中闪过一丝…… | 小说圈最恶名昭彰的AI句式 | 整句删除，换具体的身体动作或对话 |
| 心中涌起…… / 内心深处…… | AI情绪万能句式，空洞且模板化 | 删除，用身体反应代替（参考第16招） |
| 不由得/不禁/忍不住…… | 人物不需要"不由得"，读者自己能判断 | 删除"不由得/不禁/忍不住"，直接写后面的动作 |
| XX，仿佛/似乎/好像…… | 单个还好，一篇超过3个就是AI在凑比喻 | 超过3个的，砍掉一半；保留最独特那个 |
| 在……的背景下 / 随着……的发展 | AI开篇万能模板 | 直接删除整句，从第二句开始 |
| 首先…其次…再次…最后… | AI结构化列举的铁证 | 打破编号，用"还有""对了""另外"串联 |
| 不仅……更…… / 既……又…… | AI的"全面覆盖"强迫症 | 拆成两句，或者只说一半，留一半给读者 |
| XX是YY的ZZ / XX意味着YY | AI的定义癖——总想给事物下定义 | 直接陈述事实，不要下定义 |
| 空气中弥漫着…… / 空气仿佛凝固了 | 悬疑/情感类AI的高度复用句 | 换成具体的环境描写或人物感受 |
| 他/她深吸一口气…… | AI写人物"准备做某事"的标准动作 | 删除，直接写后续动作。人或紧张或犹豫时不需要"深吸一口气"才能行动 |
| 说不上来 / 难以形容 / 难以名状 | AI偷懒——写不出情绪就写「说不出」 | 删掉。如果真的说不清，写人物做了什么来回避描述这种感受 |
| 心里涌起…… / 一股莫名的…… / 没来由地…… | AI情绪万能引入——不说具体情绪，用「莫名」糊弄 | 删除。让读者从上下文自己感受到那种情绪 |
| 她/他突然意识到…… / 她/他终于明白…… | AI标配心理揭示句——人物不需要「意识到」，让他做出来 | 删除「意识到/明白」，直接写人物做了什么或说了什么 |
| 顿了几秒 / 沉默片刻 / 半晌 / 良久 | AI写对话停顿的统一模板 | 用动作填充停顿：他把烟掐了。又点了一根。她拿起杯子，喝了一口已经凉掉的水 |

## 四、节奏法则 — 人味儿的灵魂

AI最大的问题不是用词，是**节奏**。节奏对了，哪怕个别词没洗干净，人味儿也出得来。

**AI节奏的死穴：句式均匀工整**

AI文字最底层的问题是**句式高度均匀**——全篇句子长度相近、结构雷同、段落切割整齐。这是比用词更致命的AI痕迹，因为读者不需要分析，潜意识就会觉得"太顺了，不像人写的"。

**铁律**：
1. 长句（30-50字）后必须接短句（3-10字），反之亦然。
2. 一段话不允许全是用逗号串联的均匀句式。
3. 段落长度必须有变化——一段200字，下一段15字，再下一段80字。
4. 偶尔用一句话独立成段。就是这一句。就这一句的力量。
5. **不允许出现连续3句以上长度或结构相近的句子。**
6. **句式多样性检查**：随机抽取5个连续句子，如果它们都以"主语+谓语+宾语"或"她/他+动词+了+宾语"的同一模式展开——节奏不合格。真人写作会穿插倒装、省略主语、碎句、半截话。
7. **碎句和停顿是人的指纹**：真人在写作中会走神、犹豫、自己打断自己——"算了，这个先不说。""写到这突然不知道该怎么往下写了。"允许这些存在。完美流畅反而是AI的签名。
8. **对话不要轮流发言**：真人对话是碎片化的——一个人说三个字、另一个人不接话、第三个人说半句被第一个人打断。不要让对话变成"你说完→我说完→你说完"的乒乓球。

**节奏感测试**：读出声。如果读起来像和尚念经——节奏不对。有起伏有顿挫——对了。

## 五、质量自检

改写完成后逐条过：

- [ ] 读出声了吗？像人在说话吗？
- [ ] 还有没有"首先其次再次""综上所述"这种骨头架子？
- [ ] 通用AI词表 + AI模板句式表 + 该角色的专属禁用词都洗干净了？
- [ ] 节奏有没有变化？长句短句穿插了吗？有没有连续3句以上长度/结构相近的句子？
- [ ] 文章有立场吗？读得出来作者的态度吗？
- [ ] 情绪是靠"标签"在表达，还是靠动作和身体在传递？（扫一遍，不能有"他很X""她感到Y"）
- [ ] 细节有私人印记吗？还有没有"老相册""褪色照片"这类通用模板细节？
- [ ] 有至少3处人味儿标志吗？（口头禅/反问/短句突刺/插入语/情绪直言/私人细节/碎句停顿）
- [ ] 角色语气全文统一吗？
- [ ] 如果去掉标签，能骗过一个常看这类文字的人吗？
- [ ] 🆕 **人性灰度检查**：有没有100%纯良或100%纯恶的角色？「好人」有没有私心时刻？「坏人」有没有人性时刻？主角有没有面临真实的利己选项？
- [ ] 🆕 **恐惧记忆锚定检查**：恐惧场景中，感官信号是通用恐怖符号还是与人物私人创伤绑定？恐惧时有没有触发具体的记忆碎片闪回？如果去掉创伤背景，恐惧描写还能不能成立？
- [ ] 🆕 **主角推理检查**（悬疑/探案类）：主角有没有犯过至少一个推理错误？有没有走过弯路？有没有漏掉读者可能先发现的线索？还是全程推理零失误？
- [ ] 🆕 **超自然逻辑检查**（悬疑/恐怖类）：超自然规则有没有用主角个人历史做铺垫？读者重读时能不能发现前期埋的私人伏笔？如果换一个主角，超自然现象还能不能成立？
- [ ] **终极测试**：读完之后，有哪句话你能记住？如果没有——人味儿不够。
- [ ] 🆕 **干扰项检查**：所有线索都在结尾回收了吗？有没有至少1个看似有深意但从未揭晓的细节？有没有主角猜错了的方向？真人叙事一定有冗余和误判。
- [ ] 🆕 **句式情绪同步检查**：随机抽取3处人物高情绪场景（恐惧/愤怒/疲惫），检查句子形态——是工整的逗号罗列，还是随情绪破碎的句号断句？人物情绪波动时，句子有没有跟着波动？
- [ ] 🆕 **感官偏见检查**：随机抽取3处感官描写——是「准确但任何人都能写」还是「准确且只有这个人物才会这样联想」？有没有至少1处感官描写附带了一段不讲道理的、跳跃的私人联想？AI的感官永远正确；真人的感官带着情绪史。
